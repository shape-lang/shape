## Repeatable gate

Run:

```bash
just miri-provenance
```

Equivalent direct command:

```bash
direnv exec /home/dev/dev/shape-lang/shape-provenance-miri \
  bash scripts/check-miri-provenance.sh
```

The script deliberately uses:

```bash
/home/dev/.cargo/bin/rustup run nightly cargo miri test ...
```

Do not rewrite it to `cargo +nightly`: the active cargo in this devenv is
stable and does not handle that form.

The gate exits nonzero for:

- any Stacked-Borrows or Tree-Borrows regression in the trusted probes;
- a strict-provenance pass of the known failing probe, because that means this
  audit and the gate need to be updated;
- a strict-provenance failure with a different signature.

## Follow-up slices

1. Shape-value provenance carrier slice.
   Owner: shape-value carrier owner.
   Decide the strict-provenance representation for heap pointers that are
   currently stored in `ValueSlot(u64)`. Passing strict Miri requires retaining
   pointer provenance somewhere; casting address bits back to pointers is the
   blocked operation. Candidate designs should preserve the existing 8-byte ABI
   where required and may need a Miri-only or interpreter-only provenance
   sidecar if the JIT/FFI ABI must remain raw bits.

2. TypedObject slot API slice.
   Owner: shape-value plus VM carrier consumers.
   Add a single provenance-preserving accessor for `Ptr(HeapKind::TypedObject)`
   carriers. Migrate readers away from open-coded `slot.raw() as *const
   TypedObjectStorage`, then rerun strict Miri before deleting compatibility
   paths.

3. Result/Option carrier reader slice.
   Owner: `crates/shape-vm/src/executor/result_option_carrier.rs`.
   After the slot API exists, replace both the production reader at `:138` and
   the test helper at `:229` with the accessor. Keep the schema-backed
   `__Option` / `__Result` layout unchanged.

4. TypedObject raw-read sweep.
   Owner: VM typed-object accessors.
   Re-audit `crates/shape-vm/src/**` for `as *const TypedObjectStorage` and
   `as *mut TypedObjectStorage`. The current gate proves selected paths under
   Stacked/Tree Borrows; it does not prove all typed-object raw reads under
   strict provenance because the Result/Option blocker aborts first.

5. Gate flip slice.
   Owner: provenance/Miri gate owner.
   When strict provenance passes for `result_option_carrier`, change
   `scripts/check-miri-provenance.sh` so strict-provenance pass is required,
   add strict runs for the typed-object get/set property probes, and update this
   audit with the new passing signatures.
