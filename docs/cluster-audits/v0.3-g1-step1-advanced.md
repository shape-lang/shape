## §1 — Methodology + harness

### Per-snippet protocol (canonical (ii) F' harness)

1. Extract every ` ```shape ` code fence with metadata flag
   (`runnable=true|false`) to
   `/tmp/g1-slice-c/<file>-<ordinal>.shape` + `.meta`.
2. Run each snippet with the release binary built in this worktree

   - `shape run --mode vm <snippet>` → record stdout+stderr+exit

## §6 — Top divergences (team-lead summary)

### (b)-class — v0.3-gating dispatch list

These four divergence sites violate a documented contract; the doc
text was correct as design and the compiler/runtime should be brought
in line. The audit does NOT fix code (audit-day exception per the
binding brief); the team lead dispatches v0.3-gating tickets:

1. **`clone` keyword inside function-call arguments** — `process(clone data)` parser-rejects despite the doc presenting it as canonical (`ownership-deep-dive-11`). Either grammar widening to permit `clone`-prefixed expressions as call arguments, or doc-rewrite to limit `clone`-keyword to statement position only.

2. **`cview<T>` / `cmut<T>` rejected by extern-C semantic check** — marshalling matrix in `native-c-interop.mdx` documents these as supported; semantic checker emits "unsupported parameter type ... for C ABI" (`native-c-interop-1`, `native-c-interop-5`). Either C ABI marshaller accepts them, or matrix narrows the documented support level.

3. **Match-pattern enum-variant payload type inference loss** — `match s { Snapshot::Hash(id) => "...".concat(id) ... }` loses `id: string` and the binary `+` rejects `string + unknown` (`resumability-1`). Same root-cause family as shape-test-residuals-audit "typed-closure inference regressions" cluster.

(The cview/cmut issues — #2 — count as one cluster but two snippets.)
