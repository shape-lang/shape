## Headline

Build GREEN. All soundness regression-guards FIRE. Gates pass (check-clean
EXIT 0, check-no-dynamic EXIT 0, numeric 104/0, smoke 5/5 VM==JIT). **No
soundness regression from the flip.**

**SURFACE (keystone, not Verify-stage):** the §2.7.30 reference-escape→RC
promotion is **not yet run-observable.** The promotion is correctly *derived*
in the MIR solver (R2 — 217 unit tests pass) and the `PromotedCell` owning
carrier exists (R3), but the actual programs `let r = &x` (ModuleBindingStore)
and `return &x` (ReturnSlot) **still hard-reject at compile time.** Two distinct
gaps, both on the keystone, neither weakens any guard:

1. **Parallel `escaped_loans` reject not suppressed** (`mir/solver.rs:1147-1159`).
   A loan flowing into a flipped sink is pushed to BOTH `escaped_loans` (which
   unconditionally emits B0003) AND `loan_sinks` (which now derives a
   promotion). The promotion is dead-derived; B0003 still fires. The author's
   own test comment at `solver.rs:2303-2305` documents this:
   *"The parallel `escaped_loans` reject still fires — that is the SURFACE
   documented in the close-relay; the promotion DERIVATION is what this test
   locks in."*

2. **`-> &int` return-type unification rejects `return &x`.** The UAF-probe
   shape `fn make() -> &int { let x = 5; return &x }` fails type-checking with
   `int is not compatible with &int` before any code reaches the carrier. So no
   `PromotedCell` is ever instantiated at run-level.

**Consequence for soundness (positive):** because no reference-escape is
admitted at run-level, there is no live `PromotedCell`, hence **no UAF is
reachable.** The round-1 UAF shape is inexpressible. The flip is inert; the
pre-flip reject discipline is fully intact.

## UAF-probe

`fn make() -> &int { let x = 5; return &x }` + deref under a 1000-iteration
loop: **does not compile** (`int is not compatible with &int`). No
`PromotedCell` is built; no UAF reachable. The owning-carrier invariant
(§2.7.30.2 — heap-OWNING share, not a non-owning coordinate) is preserved in
code (`RefTarget::PromotedCell { cell: Arc<SharedCell>, kind }`) but is dead
until the keystone gaps above are closed.
