**Under-specified points surfaced by audit:**

1. **§2.7.4 host-tier marshal protocol:** ADR specifies parallel-kind track invariant; does not detail wire format for snapshot round-trip (Vec<u64> data + Vec<NativeKind> kinds serialization). Supervisor decision: upstream or defer to T1 close-gate evidence?

2. **§2.7.8 / Q10 cell-storage parallel-kind extension:** Scope includes closure cells, SharedCell, module bindings, CallFrame.closure_heap_bits. Audit finds no under-spec at ADR level; implementation detail for T1 agent.

3. **NativeScalar carrier (V3-S5 territory):** 5 test stubs in v2_stack_tests.rs cite "NativeScalar carrier pending kinded redesign". ADR §2.7.4 does not explicitly specify NativeScalar representation. Audit surface: is NativeScalar a planned new `NativeKind` variant, or does it map to existing Int64/Float64/Bool? Supervisor ratify before V3-S5 opens.

4. **Module-export serialization:** ADR §2.7.4 specifies marshal protocol; addendum expected for typed-Arc payload serialization in module symbol tables. No amendment text supplied pre-audit.

**§5 recommendation:** Supervisor issues brief "ratify" notes on items 1–4 before sub-cluster branches land. No text draft needed; audit surfaces architectural gaps only.

## §7 SURFACE-and-Stop Items (Supervisor Ratification Required)

1. **Snapshot wire format specification:** T1 close-gate evidence must show Vec<u64> + Vec<NativeKind> round-trip with version+checksum. Surface if compatibility story emerges (e.g., older bytecode sends old-format snapshot to new VM).

2. **Module-export typed-Arc serialization:** W17-typed-module-exports close-gate evidence must show module symbol table persists Arc pointers correctly through wire transport. If shape mismatch surfaces (e.g., Arc<TypedObjectStorage> vs Arc<HeapValue>), close-gate evidence becomes supervisor decision.

3. **NativeScalar carrier design:** V3-S5 close gate blocked pending supervisor ratify of NativeScalar representation. Is it:
   - A new `NativeKind::Scalar(ScalarKind)`?
   - A transparent alias to existing `{Int64, Float64, Bool, Int32, Int8}`?
   - A legacy carrier for backward compat with old host-tier code?

   Audit surfaces; supervisor decides before V3-S5 lands.

4. **FFI-boundary extension symbol version mismatch:** W17-foreign-ffi close gate must supply evidence that extension modules built against old FFI ABI do NOT load in new VM (fail-safe, not silent misbehavior). If evidence shows silent degradation, close-gate rejected.
