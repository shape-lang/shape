## §3 (b)-class — v0.3-gating dispatch list (DO NOT fix code at G.2 audit-day)

Names below are surface anchors; ownership goes to v0.3-gating supervisor.

1. **`state::serialize` / `state::deserialize` round-trip on `Array<number>` — JIT silent-wrong.** VM surfaces the W17-marshal-return-arms gap (`project_typed_return`, ADR-006 §2.7.4 + §2.7.5.1) as an error; JIT silently emits garbage bytes and computes wrong `.len()`. Anchor: `crates/shape-runtime/.../state` + W17 marshal-return-arms follow-up. (`/tmp/g2-step2-advanced/13_wire/s2_typed_array_roundtrip.shape`.)

2. **Annotation `comptime pre/post` hooks panic on `function` and `type` targets** at `crates/shape-vm/src/compiler/comptime_target.rs:281::nb_object_array` (V3-S5 ckpt-5 SURFACE). VM == JIT match, but compiler panic ec=101 is a contract gap relative to the runnable=true comptime.mdx + cookbook Recipe 2 (`@serializable`) examples. Anchor: V3-S5 ckpt-6 STRICT close (already in flight per ADR-006 §2.7.24 Q25.A SUPERSEDED). (`01_annotations/s3`, `03_cookbook/s1`, `03_cookbook/s3`.)

3. **`extern C fn ... from "libm"` (cos / pow / any libm symbol) cannot link.** Phase-2c extern C FFI rebuild SURFACE per ADR-006 §2.7.4 / §2.7.5. Anchor: `native_abi::link_native_function`. (`08_native/s1`, `s3`.) The native-c-interop chapter is the single normative source for FFI but every example signature that calls native code currently fails to link — the chapter ships a working subset only when `type C` declarations are isolated (s2 passes).

4. **`snapshot()` first-pass surfaces "Suspended on future <u64::MAX>" instead of `Snapshot::Hash(id)` for `match` consumption.** Doc resumability.mdx specifically marks `s2_function_level` `runnable=true`, expecting the first-pass branch to be matchable. Both VM + JIT err identically — but the documented contract was a clean match producing the hash string. Anchor: `crates/shape-runtime/stdlib-src/core/snapshot.shape` + suspension machinery. (`10_resume/s1`, `s2`.)

5. **`let r = &x; r + 1` (or `print(r)`) triggers `[B0003] reference outlives owner` while `x` is still in scope.** Doc ownership-deep-dive.mdx specifically lists this pattern as "First-Class References" and shows `let val = r + 1` as legitimate. Borrow-checker reports B0003 at the binding site, suggesting the borrow-solver does not narrow `r`'s region to the trailing arithmetic use. (`09_ownership/s3`, `s3b`.)
