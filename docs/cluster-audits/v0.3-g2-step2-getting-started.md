## §3 (b)-class v0.3-gating items (NEW for team-lead dispatch)

### B-1 — JIT SIGSEGV (deterministic) on `basic-concepts.mdx §6 Option/Result + match` doc example

**Doc cite:** `shape-web/book/book-site/src/content/docs/getting-started/basic-concepts.mdx` L109–122 (the §6 "Option/Result and Error Propagation" example, the bare `shape` fence — no `runnable=true` attribute, but it is a documented user-facing pattern).

**Repro program** (verbatim from doc, `/tmp/g2-step2-getting-started/bc-8-option-result.shape`):

```shape
fn require_file(name: Option<string>) -> Result<string, string> {
  match name {
    Some(path) => Ok(path)
    None => Err("missing input filename")
  }
}

let file = Some("events.csv")
match require_file(file) {
  Ok(path) => print(f"path: {path}")
  Err(msg) => print(f"error: {msg}")
}
```

**Empirical result (HEAD `0c56ab86`):**
- VM: `path: events.csv` / ec=0 (correct, matches doc)
- JIT: **SIGSEGV (ec=139, `Segmentation fault (core dumped)`)** — **deterministic** across 5/5 re-runs, no `[jit-fallback]` warning emitted (JIT compiled then crashed during execution; this is NOT the R8 W7 G.5 fallback surface)

**Bisection** (`/tmp/g2-step2-getting-started/bc-8-min{1..6}*.shape`):

| Minimal repro | VM | JIT | Triggers? |
|---|---|---|---|
| min1: bare `match Some(literal)` | OK | OK | no |
| min2: bare `let r: Result<...> = Ok(...); match r {...}` | OK | OK | no |
| min3: zero-arg fn returning `Result<string,string>`, top-level `match call() {...}` | OK | OK | no |
| min4: fn `Option<string> -> Result<string,string>`, no outer match | OK | OK | no |
| **min5**: fn `Option<string> -> Result<string,string>` + inline `Some("events.csv")` arg + top-level `match call(...)` | OK | **SIGSEGV** | **YES** |
| min6: same Option→Result match chain inline (no fn indirection) | OK | OK | no |

**Trigger surface (empirical):** the SIGSEGV requires (a) a fn whose parameter is `Option<string>` AND return is `Result<string, string>`, where the body matches the Option payload and rewraps as Result, AND (b) a top-level `match` on the call-site that destructures the Result's `Ok(path)`/`Err(msg)` arms binding string payloads. Removing either the fn indirection (min6), the outer match (min4), or the Option arg (min3) eliminates the crash. Minimum-trigger = `min5`.

**Expected vs actual:**
- Expected (per doc + per VM ground-truth): `path: events.csv` ec=0 on JIT.
- Actual: ec=139 (SIGSEGV) on JIT, no output, deterministic.

**Classification rationale (per dispatch §Discipline classification rule):**
- (a) candidate: NO — doc is a correct contract; the documented behavior works under VM.
- (b) candidate: **YES** — doc was a contract; JIT execution path is wrong (silent execution-path crash vs. documented expected output). Per dispatch "If JIT crashes / SIGSEGVs → (b)". Per catch-pre-merge precedent (R8 W7+W8 aliased-CoW + Cluster-A-JIT-divergence), execution-path SIGSEGVs cannot be (c).
- (c) candidate: NO — Option<T> + Result<T,E> + `match` payloads are all v0.3-shipped features (documented in basic-concepts and in fundamentals/errors per the doc's own cross-ref); the feature is not v0.4-deferred.

**ADR cross-ref candidates** (for team-lead dispatch triage):
- **ADR-005 §1 (single-discriminator)** + **ADR-005 §2 (`TypedFieldValue::String(Arc<String>)` exception)**: payload is a string-typed Option/Result. Crash may sit at the kind-stamping/refcount boundary for the Result `Ok(String)` payload as constructed inside the fn and matched at the call site (cross-frame string `Arc` lifetime under JIT).
- **ADR-006 §2.7.7 / Q9** (parallel `Vec<NativeKind>` stack track) + **§2.7.11 / Q12** (value-call ABI `KindedSlot` carriers): the trigger requires the call-frame round-trip of an Option<string> arg + Result<string,string> return — a `KindedSlot` carrier with `NativeKind::Ptr(HeapKind::TypedObject)` (enum payload) across JIT-emitted call convention.
- Distinct from R8 W7 G.5 SURFACE (V2 typed-opcode FrameDescriptor — that path falls back to interp cleanly; this one JIT-executes then crashes).
- Distinct from cluster-1.5 v2-raw-heap (those were SIGABRT allocator-pair mismatches; this is SIGSEGV).

**Severity:** v0.3-gating. The example is a foundational doc-truth surface in the getting-started chapter (`basic-concepts §6`) — first thing a user reads about error handling. JIT is the default execution tier; user following the doc on default settings gets a crash.

**Suggested next step (NOT executed in this slice per dispatch):** team-lead dispatches a single-cluster audit on the bc-8-min5 minimum-trigger to localize between the call-convention boundary and the match-payload extract paths. Hand-off candidates noted above.
