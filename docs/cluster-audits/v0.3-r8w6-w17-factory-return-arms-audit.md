## §4 Disposition — Group 1 fix (mechanical)

**Fix recipe:**

### Step 1 — `crates/shape-value/src/kinded_slot.rs`

Add two convenience constructors mirroring existing `ValueSlot` patterns:

```rust
pub fn from_io_handle(h: Arc<IoHandleData>) -> Self {
    Self::new(
        ValueSlot::from_io_handle(h),
        NativeKind::Ptr(HeapKind::IoHandle),
    )
}

pub fn from_data_table(d: Arc<DataTable>) -> Self {
    Self::new(
        ValueSlot::from_data_table(d),
        NativeKind::Ptr(HeapKind::DataTable),
    )
}
```

Both underlying `ValueSlot::from_io_handle` (line 389) and
`ValueSlot::from_data_table` (line 383) already exist. Drop/Clone
dispatch tables already carry the matching `HeapKind::IoHandle` + 
`HeapKind::DataTable` arms (`kinded_slot.rs:863, 868`). ADR-005 §1
single-discriminator preserved.

### Step 2 — `crates/shape-vm/src/executor/vm_impl/modules.rs:61-67`

Add the two specific arms to `project_typed_return`:

```rust
ConcreteReturn::IoHandle(h) => Ok(KindedSlot::from_io_handle(h)),
ConcreteReturn::DataTable(d) => Ok(KindedSlot::from_data_table(d)),
other => Err(VMError::NotImplemented(format!(
    "project_typed_return: W17-marshal-return-arms residual — \
     ConcreteReturn::{:?} arm has no in-session KindedSlot projection. \
     Tracked as W17-followup. ADR-006 §2.7.4.",
    std::mem::discriminant(&other)
))),
```

The catch-all retains the existing SURFACE message for the still-residual
arms (ArrayHeapValue / HashMapStringHeapValue + Result/Option container
arms).

### Step 3 — JIT side

The transport::tcp divergence (VM ec=1, JIT ec=0) eliminates automatically
once both tiers reach the same `project_typed_return` arm gate: post-fix
both succeed (returning a valid IoHandle slot). No separate JIT codegen
work required — the JIT already calls through `project_typed_return`.

**Estimated effort:** 1-2 hours (mechanical add).
**Discipline gates:** all close-gates preserved by construction
(no Forbidden Patterns, no Renames-to-refuse, no parallel-implementation
across producer/consumer; the fix is a typed-Arc constructor addition
