## §4 Notable defect patterns (single root cause)

**Pattern P1: `fn python/typescript ... -> T { ... }` without `Result<T>` wrapper.** All 8 polyglot.mdx ` ```shape ` blocks + 1 python-extension.mdx + 1 typescript-extension.mdx site used bare return types. Compiler error: `Foreign function '<name>': return type must be Result<<T>> (dynamic language runtimes can fail on every call)`. Pattern source: pre-strict-typing draft when the "static error model" was still planned; the runtime never shipped that branch (every foreign runtime advertises `error_model: Dynamic`). Root reference: `crates/shape-runtime/src/.../foreign_*` semantic-check (compile-time) + per-extension `error_model` vtable field (already documented at polyglot.mdx L269).

**Pattern P2: docstrings.mdx uses non-Shape pseudo-syntax for traits.** Three places use `method(): ReturnType` instead of `fn method() -> ReturnType;`, and one place uses `type X = { ... ; ... }` instead of `type X { ... , ... }`. Compares to canonical `fundamentals/traits.mdx` which is correct. Root: docstrings.mdx authored before the trait/type-decl syntax stabilized.

**Pattern P3: docstrings.mdx `spread()` uses gated `__intrinsic_max/__intrinsic_min`.** User code cannot call `__intrinsic_*` per CLAUDE.md `Builtins & Intrinsics`. Replaced with the array-method form `series.max() - series.min()`.
