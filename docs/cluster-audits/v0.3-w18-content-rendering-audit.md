## §7 SURFACE-AND-STOP items (require user / supervisor decision before fix dispatch)

### Item 1: Enum Display default semantics — USER decision needed

When NO user-defined Display impl exists for an enum, what should `print()` output?

| Option | Output for `Color::Blue(42)` | Rationale |
|---|---|---|
| (a) Variant(payload) form | `Blue(42)` | Pretty; matches Rust default; recommended |
| (b) Generic `{__variant, __payload_*}` | `{__variant: 0, __payload_0: 42}` | Honest internal repr; current behavior |
| (c) Comptime hook `@display_default` per-enum | user-chosen | Adds annotation surface area; v0.4 territory |

**Audit recommendation:** Option (a). Falls back to (b) if schema lookup fails. (c) is scope-creep — reject per Refusal #10.

### Item 2: Display trait method name — USER decision needed

User-defined Display trait method signature:

| Option | Shape | Note |
|---|---|---|
| (a) `method format() -> string` | Matches CLAUDE.md §Language Features `impl Display for Point` example (line ~132) | Recommended; aligns existing docs |
| (b) `method to_string() -> string` | More Rust-idiomatic | Conflicts with existing primitive `to_string` conversion semantics |

**Audit recommendation:** Option (a). Surfaces to user; supervisor ratify if cross-binding concerns.
