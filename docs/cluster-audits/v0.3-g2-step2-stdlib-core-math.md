### Δ8: `log::error` name shadows comptime builtin `error`

`from std::core::log use { error }` then `error(l, "boom")` is rejected:
`'error' is a comptime-only builtin and can only be called inside a
`comptime { }` block`. The log module exports `error` but the user can't
call it bare-name without a from-use rename. This is consistent with the
pre-existing `format()` shadowing constraint (CLAUDE.md §Known
Constraints). → Class (a) **doc-fix** — chapter examples should show
`from std::core::log use { error as log_error }` OR omit the `error`
example. Practical workaround: use any of trace/debug/info/warn for
chapter examples.
